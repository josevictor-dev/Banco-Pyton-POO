Banco Python S.A (Sistema Bancário em POO)
Este repositório contém uma implementação de um sistema bancário simples, desenvolvido em Python, utilizando os conceitos de Programação Orientada a Objetos (POO). O projeto faz parte do desafio de código da plataforma DIO.

Funcionalidades
O sistema permite gerenciar contas bancárias com as seguintes operações:

Login: Acesso seguro utilizando CPF e senha.

Criar Conta: Registro de novos usuários com saldo inicial.

Depositar: Adição de valores ao saldo da conta atual.

Sacar: Retirada de valores respeitando o saldo disponível.

Extrato: Visualização de todas as transações realizadas.

Tecnologias e Conceitos Aplicados
Linguagem: Python 3.14+.

Paradigma: Orientação a Objetos (Classes, Métodos, Atributos).

Estrutura de Dados: Uso de Dicionários para busca eficiente de contas por CPF.

Controle de Versão: Metodologia Gitflow para organização de branches (main, develop, feature).

Como Executar
Certifique-se de ter o Python instalado.

Clone o repositório:

Bash

git clone https://github.com/josevictor-dev/Banco-Pyton-POO.git
Navegue até a pasta e execute o script:

Bash

python conta_bancaria.py
